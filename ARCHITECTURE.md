# Architecture

The application uses a MERN structure with separate workspaces:

- `frontend/`: React application built and served with Vite.
- `backend/`: Express API, Mongoose persistence, Gemini integration, and media providers.
- `backend/src/routes/`: authentication, investigation, evidence, media, and health APIs.
- `backend/src/services/ai/`: Gemini client, structured output schemas, validation, and retry handling.
- `backend/src/services/investigation/`: asynchronous generation orchestration.
- `backend/src/services/media/`: image/video provider adapters and local media storage.
- `backend/src/prompts/`: case and evidence prompts.

Vite proxies `/api` requests to the backend in development. The backend loads its environment from `backend/.env`, applies the configured client origin for CORS, and connects to MongoDB before listening. Secrets belong in local environment files and must not be committed.

Authentication uses Mongoose user records, bcryptjs password hashing, signed JWT session cookies, and authentication middleware. The frontend restores the session from `/api/auth/me` and guards the dashboard, case creation, and investigation views. Investigation and media APIs enforce owner checks.

Case generation runs asynchronously after a validated scenario is persisted. The worker requests a structured case blueprint and a separate evidence plan from Gemini, validates both structurally and semantically, then persists public case material and private solution fields separately. Images and CCTV-style videos use backend-only provider adapters. Evidence metadata is stored in MongoDB; generated bytes are stored locally in `backend/storage/media/` by default. Provider or media failures are reflected in generation status without fabricating content.

The culprit, solution, clue plan, generation diagnostics, accusation, and saved result are excluded from normal queries or explicitly omitted from API projections. Accusation handling validates the authenticated owner and suspect, computes the result and score on the backend, then atomically completes the investigation once. The result endpoint only reveals the saved solution after that submission.
